# Vaporetto Guide

An independent English-language field guide to the Venetian **vaporetto** — the word,
the boats, the fares and the routines. The homepage targets the query
“vaporetto meaning”; the supporting pages cover the adjacent intents (what it is,
pronunciation, etymology, riding, tickets, gondola comparison).

Live: <https://vaporettoguide.com/> (GitHub Pages, custom domain).
Transitional URL: <https://fasten888.github.io/vaporetto-guide/>.
See [DEPLOY.md](DEPLOY.md) for DNS and Search Console steps.

## Stack

Plain HTML, one stylesheet, ~2 KB of JavaScript and a Python build script. No
framework, no bundler, no third-party fonts, analytics or trackers.

- `content/*.html` — page bodies (the only files you normally edit).
- `templates/base.html` — shell: head, nav, footer, JSON-LD slot.
- `assets/style.css` — all styling, mobile-first breakpoints at 1060/920/640 px.
- `assets/img/*.svg` — original illustrations (hero and ticket).
- `assets/og/*.png` — 1200×630 social cards, generated by `tools/make_assets.py`.
- `build.py` — renders pages, breadcrumbs, JSON-LD, sitemap, robots, `404.html`.

## Build

```bash
python3 build.py
# or, for the production URL:
SITE_URL=https://fasten888.github.io BASE_PATH=/vaporetto-guide python3 build.py
```

`BASE_PATH` must match the path the site is served from (`/vaporetto-guide` on a
GitHub Pages project site, empty string on a custom domain).

Output goes to `dist/`.

## Check

```bash
python3 tools/check_site.py
```

Verifies internal links, canonical/OG metadata, JSON-LD, alt text, heading order,
duplicate titles/descriptions and that the sitemap matches the canonicals.

## Regenerate social cards and icons

```bash
python3 tools/make_assets.py
```

Requires Google Chrome for the cards and Pillow for the icons (`pip install pillow`).
The PNGs are committed, so CI does not need either.

## Deploy

Push to `main`; GitHub Actions builds `dist/` and publishes it to Pages. See
[DEPLOY.md](DEPLOY.md) for the one-time setup, custom-domain migration and Search
Console steps.

## Editorial rules

- Every fare figure is dated and attributed to ACTV/Venezia Unica.
- Approximate figures are labelled as approximate.
- Corrections go through the GitHub issue link in the footer.
